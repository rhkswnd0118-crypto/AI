# AGENTS.md 권장 구조

## 저장소 레이아웃
- src/ : 소스코드
- tests/ : 테스트

## 빌드 / 테스트 명령
- npm run lint
- npm test

## 엔지니어링 규칙
- TypeScript strict 모드
- 함수명은 camelCase

## 완료 기준
- 모든 테스트 통과
- 타입 에러 없음
최대 크기: 32KB

설치 & 시작하기

CLI 설치

# npm으로 설치
npm install -g @openai/codex

# Mac에서 brew로
brew install codex

# API 키 설정
export OPENAI_API_KEY="sk-..."

바로 사용

# 자연어로 지시
codex "README.md에 설명 추가해줘"

# 특정 파일 수정
codex "날짜 포맷을 YYYY-MM-DD로"
